# 假面骑士吧长帖审阅助手

一个非百度官方、面向 Chrome 的 Manifest V3 侧栏扩展。打开贴吧帖子并保持侧栏开启后，它会通过贴吧只读端点读取接口可见的全部楼层和楼中楼，再把完整快照交给吧务决定是否进行可能计费的 AI 初筛。模型只生成待人工复核的线索；不会后台巡检，也不会执行删除或封禁。1.0.0 已在 Chrome 实机验收；Edge 与 Tabbit 保留兼容实现，但不列为本次正式版已验收平台。

## 安装

1. 安装 Node.js `^20.19.0` 或 `>=22.12.0`，运行 `npm ci && npm run build`。
2. 在 Chrome、Edge 或 Tabbit 打开 `chrome://extensions` 并开启“开发者模式”。
3. 选择“加载已解压的扩展”，指向本项目构建生成的 `dist` 目录。
4. 打开 `https://tieba.baidu.com/p/...` 帖子并点击扩展图标。侧栏会自动读取整帖；也可以点击右上角读取按钮明确刷新快照。

扩展持久申请 `https://tieba.baidu.com/*`，以兼容不会为侧栏按钮授予 `activeTab` 的 Tabbit。已配置的百炼工作区保持精确固定授权；DeepSeek 只声明精确的 `https://api.deepseek.com/*` 可选权限，由吧务点击“授权 DeepSeek 并分析”后持久授予，直到在浏览器扩展设置中撤销。两项 AI 权限都只允许向对应 API 域名发请求，不允许读取其他网站正文。

整帖读取主路径固定调用同域的 `sync`、`page_pc` 与楼中楼分页读取端点，按每一页返回的分页前沿、楼中楼当前可用数量和稳定 PID/SPID 去重校验。已由 `page_pc` 稳定预览完整覆盖的父楼不会再重复请求楼中楼端点；其余父楼串行读取，降低触发安全验证和限流的概率。楼中楼解析只接受唯一分页节点的同级标准回复，并逐页核对原始节点数、稳定 ID、重复 ID、未知结构和分页元数据漂移；终页标注数大于实际节点数时还会额外探测下一页是否为贴吧的精确空页哨兵。读取只发生在侧栏打开的当前帖子，不会扫描首页或全吧。贴吧同域只读请求会由浏览器按正常网页规则携带当前登录态，但扩展不申请 `cookies` 权限、不直接读取或导出 Cookie。扩展不会发帖、删帖、封禁或调用吧务写入端点。若只读端点失效，才会退回旧版分页 DOM / 新版虚拟列表 DOM 的部分读取，并明确显示具体失败阶段、分页与数量；这种降级结果不会自动外发给模型。

即使所有接口分页都读取成功，贴吧标注回复数与实际可返回的稳定回复 ID 仍可能因删除、审核中、当前账号可见性或接口统计时点存在差额；图片文字也不会自动识别。只有在终页、节点结构、稳定 ID、去重、分页一致性和终页后空页探测全部通过时，纯数字差额才会作为非阻断的“站点统计差额”，AI 只分析实际取得的文字；重复 ID、未知节点、ID 冲突、分页漂移或探测异常仍会安全阻断。这些情况都不会被包装成“整帖安全”。证据定位严格留在当前页面：当前版本只会尝试安全切换正序、滚动虚拟列表、展开明确的只读楼中楼控件并高亮目标，不会自动换页或刷新。若目标尚未挂载，侧栏会在原页提示；legacy DOM 证据位于其他分页时也由用户自行切换页面后重试。

读取和 AI 任务都绑定发起时的标签页与帖子快照。切换到另一个浏览器标签只会切换侧栏显示，不会取消原任务，也不会把 A 帖结果挂到 B 帖；原标签真正导航离开时，未完成读取会停止，已经发出的 AI 请求仍按原快照等待和保存。整帖请求由保持打开的侧栏承载，关闭侧栏后不能假定它仍在浏览器后台持续运行。

## 已实现能力

- 一次点击后以并发 3 动态读取主回复分页；仅对预览尚未完整覆盖的父楼串行读取楼中楼，解析作者、楼层、时间和文字内容；DOM 仅作为接口失败时的降级与原文定位手段。
- 读取请求绑定明确的 `tabId/requestId`，通过 `CAPTURE_PROGRESS` 展示真实阶段与已完成/总量；切换浏览器标签不会取消目标帖读取，也不会把进度串到当前帖子。
- 整帖模式显示主回复页数、楼中楼实取/声明数、不可见数量差额与未识别图片；接口结构变化或请求失败不会保存为空的“成功”结果。
- 本地只负责整帖读取、覆盖校验、脱敏和安全定位；待复核线索只采用完整整帖 API 模型结果，不再生成本地风险分数或本地补充线索。
- 内置 PDF 中全部 16 类、112 条规范理由，公开理由始终使用原文。
- 普通/夜间两套贴吧风格主题；正文、焦点、键盘操作、窄屏布局和付费确认弹窗均按侧栏场景调整。
- 打开侧栏、切换功能页、悬停与按压按钮、选择线索、展开卡片和切换主题均有克制的过渡动效；系统启用“减少动态效果”时会完整关闭装饰动画。
- 结果页按“初筛总览 → 最高优先级 → 待复核线索 → 当前处理对象 → 待人工确认 → 折叠详情”排列，不会自动选择第一条线索或替用户决定。
- 每条线索默认只展示对象、严重程度、模型把握、主证据与完整规范原文；支持展开结构化证据、上下文和待确认信息。
- “历史”页按每次成功的整帖 AI 分析保存初筛总览、线索、结构化报告、模型配置和 token 回执；人工决定会关联到准确的分析次数与线索。失败、断连与发送状态只保留防重复计费所需的最小回执，不会被伪装成成功报告。旧版独立审核决定仍保留，但不会被伪装成 AI 结果。
- 设置 schema v2 将免费读取与付费分析拆开：`autoReadWholeThread=true`、`autoAnalyzeWholeThread=false`；完整快照始终提供手动“开始 AI 初筛”入口。
- 整帖 AI 请求一次包含接口可读的全部主楼、楼中楼和版本化的 112 条规则，不依赖本地算法预先挑选冲突。
- v3 精简协议返回 `summary + findings + report{overview,stages,interactions,notes}`；自由文案不展示 P/U/R 编号，回复引用只从结构化 `replyIds` 严格映射。旧版七段报告仍可读取，但只在“旧版详细报告”中折叠展示。
- 模型线索使用独立证据卡，显示真实楼层、楼中楼关系、用户名、时间、原文摘录和本地规范原文，可直接回原帖定位。
- 模型误把没有明确回复、点名、楼层引用或连续互动关系的主回复合并时，结果会按可验证互动链拆开，不再把相距很远的独立发言包装成同一冲突。
- 作者替换为 `U1/U2`，回复标识替换为本次请求内的 `P1/P2`；手机号、邮箱、身份证、QQ、微信等会在发送前脱敏。
- 模型必须区分可能涉及规范的回复与普通上下文，每组线索只选一个最直接理由；未知回复 ID、未知规则 ID 和同一回复的低置信度重复判断会被本地丢弃。
- 点击任意模型引用的楼层时，只在当前页面内切正序、快速扫描虚拟列表并高亮精确 PID；楼中楼只自动点击明确的“展开/查看更多回复”只读控件。定位失败或 legacy 证据位于其他分页时只在原页提示，不会自动换页或刷新。
- 理由库按 16 类就地单分类展开，规则正文不重复分类名；全局搜索按分类分组并分批显示。内置 `review-clean`、`review-typical`、`review-dense` 三套纯合成演示态，不调用模型或保存真实语料。

## 云端分析边界

在“设置”中选择阿里云百炼或 DeepSeek，填写该服务商的 API 密钥并点击保存。选择 DeepSeek 时会使用官方 `/chat/completions` 端点和项目当前默认模型；两家凭据分别保存，切换服务商只会读取对应凭据，不会跨服务商复用。免费自动读取默认开启，自动创建付费 AI 请求默认关闭；完整快照就绪后由吧务点击“开始 AI 初筛”，也可以明确选择开启自动分析。

- 快速模式关闭受支持模型的思考，整帖最长等待 3 分钟。深度模式对 Qwen 开启思考，对 DeepSeek 发送 `thinking.enabled` 和 `reasoning_effort: max`，并等待最长 10 分钟。
- 整帖分析只使用 Manifest 中精确列出的百炼工作区或 `api.deepseek.com`。DeepSeek 未授权时不会发送正文；显式授权会持续保留，不在每次请求后重复申请或撤销。
- 整帖请求由保持打开的侧栏直接等待结果，不依赖可能被 Tabbit 回收的 Manifest V3 service worker。切换浏览器标签不会取消或转移任务；关闭侧栏后不能保证请求继续等待，缓存会保守标为结果未知且不会自动重发。
- API 密钥按服务商独立保存在此 Chrome 配置文件的 `chrome.storage.local`，Chrome 重启、扩展更新和重新加载后仍保留；它不会同步、导出、写入普通设置或分析历史。扩展会把该存储区限制为可信扩展上下文，但浏览器扩展存储不是操作系统密钥库级加密；卸载扩展、更换 Chrome 配置文件或清除扩展数据会删除凭据。
- 请求不包含帖子 URL、官方 PID/SPID、精确时间、原用户名、图片、Cookie、密码或贴吧登录信息。
- 规范化帖子快照只在内存中参与 SHA-256，并生成不含明文的 `SnapshotId`；快照、服务商、端点、模型、模式、规则和分析器版本共同生成 `AnalysisKey`。同一精确分析输入可按该键复用；正文变化才产生新快照。
- cache v3 存于 `chrome.storage.local`，区分 `preparing`、`running`、`success`、发送前/后失败、发送前/后取消和断连后未知共八种状态，负责运行态与异常恢复。另有按 `SnapshotId` 分键的最小计费回执，只保存哈希、尝试 ID、状态和时间，不保存帖子身份、正文、用户名、模型结果或密钥；同一快照开始任务前必须先通过跨侧栏独占锁取得原子占位。成功结果写入历史后可以清除重复的临时结果副本，但计费回执仍会阻止扩展更新、设置切换、报告删除或损坏数据被误当成“从未分析”而自动再次付费。只有紧邻真实请求发送前才写入 `sentAt`；已发送、已成功、结果未知或报告已删除的快照再次分析，都必须由用户明确确认费用。
- 成功结果写入按 `attemptId` 独立保存的 AI 分析历史：保存帖子标题、模型生成的摘要/线索/报告、引用楼层位置、模型配置和 token 回执，不单独保存原始回复正文、用户名或证据摘录。模型生成文字可能概括或复述讨论内容；历史仅保存在当前 Chrome 配置文件，可单独导入、导出和删除，不会连带清除 API 密钥、人工决定或防重复计费标记。
- 同一侧栏最多同时运行两项付费分析；第三项不启动、不排队，之后也不会暗中自动发送。设置修改只影响未来任务。
- v3 分析器安全规范化 Qwen/DeepSeek 常见 JSON 差异，并仅依据父子回复、明确楼层引用、“楼上”、@或点名关系聚合互动链；未知或变形回复 ID 不会生成可点击目标，未知规范 ID 不会成为理由，截断输出整份拒绝。
- 思考模式的 `reasoning_content` 不会被显示、缓存或拼进结果；侧栏只使用模型的最终 `message.content`。
- 项目当前为 DeepSeek V4 整帖请求配置 384,000 输出 token；单项分析和其他服务商仍使用较小预算，避免把不兼容的参数发往其他端点。服务商仍可能拒绝该参数，或因总上下文、模型可用性与自身资源限制提前结束；任何截断 JSON 都会整份拒绝。
- 请求体超过安全字节或保守 token 上限时零请求，不截断、不只发送前半帖。
- 模型返回的理由文字不会直接成为公开文案；界面始终按模型给出的合法规则 ID 重新读取本地规范原文。
- “待人工确认”的相关回复会从当前本地快照直接补回楼层、用户、时间与原文摘录；长回复可在侧栏内展开全文，屏蔽占位符和纯图片回复会明确标注，定位操作仍只在当前贴吧页面内完成。
- 服务商返回标准 token usage 时，本机按月记录成功请求次数及输入/输出/合计 token；没有 usage 回执的调用不会被猜测补齐，人民币金额始终以服务商后台账单为准。

## 开发与验证

```bash
npm run typecheck
npm test
npm run build
npm run evaluate:example
```

`npm run evaluate:example` 只验证旧版本地启发式分析器的评估工具与语料格式；生产侧栏已不再使用这套本地判定。需要回归这部分遗留代码时，可将至少 30 个经人工标注、已脱敏的案例放入被 Git 忽略的 `evaluation/private/`，再运行：

```bash
npm run evaluate -- evaluation/private/corpus.json
```

该评估命令不调用云端模型，也不能代表整帖 AI 审阅质量；500 条 DOM 读取性能另由提取器测试覆盖。真实语料没有随代码提交，避免把吧友发言和用户名长期复制进仓库。

## 当前限制

- 只读端点只能返回当前账号/匿名会话可见的回复；已删除、审核中或权限不可见的内容无法绕过贴吧限制读取，数量差额会明确展示。
- 图片和视频内容不做 OCR；图片数量会计入覆盖缺口。
- 贴吧接口或 DOM 改版后可能需要更新适配；接口异常、加载中、结构不支持和解析异常会分别提示，空结果不会保存为有效审阅会话。
- `sync`、`page_pc` 等属于贴吧网页使用的非公开只读接口，可能随时调整或受平台规则约束；使用者应自行确认其账号与场景符合贴吧规则。
- 模型仍可能误解引用、反讽、熟人玩笑或事实真伪；所有结论和可点击证据都必须由吧务回到原帖人工复核。
- 首页全吧风险队列、OCR、团队共享后台和自动处罚均不在 1.0.0 范围内。

## 正式版与隐私

当前正式版本为 `1.0.0`。隐私边界、数据保存位置、外发内容、权限用途和删除方式见 [PRIVACY.md](./PRIVACY.md)，版本变更见 [CHANGELOG.md](./CHANGELOG.md)。

生成不含 source map 的 Chrome 扩展 ZIP：

```bash
npm run release:verify
```

命令会先运行全量测试和生产构建，再仅从 `dist/` 白名单文件生成 `release/tieba-long-thread-review-assistant-1.0.0.zip`，同时写出 SHA-256 校验文件与构建清单。正式包的 ZIP 根目录直接包含 `manifest.json`。Windows Chrome 普通用户不能直接双击安装这个 ZIP；它可解压后在开发者模式加载，或作为后续 Chrome Web Store 审核上传的基础包。
- 本机分析历史最多保存 100 次，单条与全部历史共享 4 MiB 总预算；预算按实际存储键及值 JSON 的 UTF-8 字节计算。保存或导入会先完整校验，超限时整批拒绝并明确提示用户导出或删除，不会静默淘汰旧报告或只写入一部分；多个 Chrome 侧栏实例的写入也会通过同源独占锁串行。
