# 假面骑士吧长帖审阅助手

一个非百度官方、面向 Chrome、Edge 与 Tabbit 的 Manifest V3 侧栏扩展。打开贴吧帖子并保持侧栏开启后，它会通过贴吧只读端点一次读取接口可见的全部楼层和楼中楼，并在配置完成时把整帖脱敏文字连同 112 条规范理由一次性交给模型审阅。模型只生成带原文证据的违规线索；不会后台巡检，也不会执行删除或封禁。

## 安装

1. 安装 Node.js `^20.19.0` 或 `>=22.12.0`，运行 `npm ci && npm run build`。
2. 在 Chrome、Edge 或 Tabbit 打开 `chrome://extensions` 并开启“开发者模式”。
3. 选择“加载已解压的扩展”，指向本项目构建生成的 `dist` 目录。
4. 打开 `https://tieba.baidu.com/p/...` 帖子并点击扩展图标。侧栏会自动读取整帖；也可以点击右上角读取按钮明确刷新快照。

扩展持久申请 `https://tieba.baidu.com/*`，以兼容不会为侧栏按钮授予 `activeTab` 的 Tabbit。已配置的百炼工作区保持精确固定授权；DeepSeek 只声明精确的 `https://api.deepseek.com/*` 可选权限，由吧务点击“授权 DeepSeek 并分析”后持久授予，直到在浏览器扩展设置中撤销。两项 AI 权限都只允许向对应 API 域名发请求，不允许读取其他网站正文。

整帖读取主路径固定调用同域的 `sync`、`page_pc` 与楼中楼分页读取端点，按贴吧返回的总页数、楼中楼声明数和稳定 PID/SPID 去重校验。读取只发生在侧栏打开的当前帖子，不会扫描首页或全吧。贴吧同域只读请求会由浏览器按正常网页规则携带当前登录态，但扩展不申请 `cookies` 权限、不直接读取或导出 Cookie。扩展不会发帖、删帖、封禁或调用吧务写入端点。若只读端点失效，才会退回旧版分页 DOM / 新版虚拟列表 DOM 的部分读取，并明确显示覆盖缺口；这种降级结果不会自动外发给模型。

即使所有接口分页都读取成功，贴吧标注回复数与实际可返回的稳定回复 ID 仍可能因删除、审核中或可见性规则存在差额；图片文字也不会自动识别。这些都会单独列为覆盖缺口，不会被包装成“整帖安全”。若证据当前没有挂载在虚拟列表中，0.3.1 会先在当前页内尝试切换正序、滚动虚拟列表并展开楼中楼；只有在限定时间内仍找不到时，才使用贴吧官方 PID/CID 地址刷新定位。

同一标签页一旦离开该帖子（进入另一帖或其他网站），旧审阅会话会立即失效，避免误把旧证据记到新页面；返回后需要重新点击“读取整帖”。

## 已实现能力

- 一次点击后并发读取主楼分页与楼中楼分页，解析主楼、楼中楼、作者、楼层、时间和文字内容；DOM 仅作为接口失败时的降级与原文定位手段。
- 整帖模式显示主回复页数、楼中楼实取/声明数、不可见数量差额与未识别图片；接口结构变化或请求失败不会保存为空的“成功”结果。
- 本地只负责整帖读取、覆盖校验、脱敏和安全定位；违规判定只采用完整整帖 API 模型结果，不再生成本地风险分数或本地补充线索。
- 内置 PDF 中全部 16 类、112 条规范理由，公开理由始终使用原文。
- 模型摘要、长文报告、边界说明、违规理由、证据解释和待确认项中引用的具体回复都会显示可点击的真实楼层与用户名；同时支持理由搜索/复制和最小化审核记录。
- 审核记录采用 `schemaVersion: 1.0` 的严格 JSON，只保存帖子/回复标识、决定、理由和版本，不保存完整正文或用户名。
- 自动整帖 AI 审阅：一次请求包含接口可读的全部主楼和楼中楼，以及版本化的 112 条规则；不依赖本地算法先挑出冲突。
- DeepSeek 深度模式返回七段式长文报告：整帖主题、讨论脉络、参与者互动、吧务复核优先级、边界案例、激烈但正常的讨论和覆盖缺口。
- 明确违规仍使用独立证据卡，显示真实楼层、楼中楼关系、用户名、时间、原文摘录和规范原文，可直接回原帖定位。
- 模型误把没有明确回复、点名、楼层引用或连续互动关系的主回复合并时，结果会按可验证互动链拆开，不再把相距很远的独立发言包装成同一冲突。
- 作者替换为 `U1/U2`，回复标识替换为本次请求内的 `P1/P2`；手机号、邮箱、身份证、QQ、微信等会在发送前脱敏。
- 模型必须区分实际违规回复与普通上下文，每组线索只选一个最直接理由；未知回复 ID、未知规则 ID和同一回复的低置信度重复判断会被本地丢弃。
- 点击任意模型引用的楼层时，优先在 SPA 内部切正序、快速扫描虚拟列表并高亮精确 PID；楼中楼只自动点击明确的“展开/查看更多回复”控件。

## 云端分析边界

在“设置”中选择阿里云百炼或 DeepSeek，填写本次浏览器会话使用的 API 密钥并点击保存。选择 DeepSeek 时会自动使用官方 `/chat/completions` 端点、`deepseek-v4-pro` 和深度模式；切换服务商会立即清空当前密钥，避免把一家的凭据发给另一家。完整整帖快照准备好后会自动发起一次分析，不再要求吧务逐条选择冲突。

- 快速模式关闭受支持模型的思考，整帖最长等待 3 分钟。深度模式对 Qwen 开启思考，对 DeepSeek 发送 `thinking.enabled` 和 `reasoning_effort: max`，并等待最长 10 分钟。
- 自动整帖分析只使用 Manifest 中精确列出的百炼工作区或 `api.deepseek.com`。DeepSeek 未授权时不会发送正文；显式授权会持续保留，不在每次请求后重复申请或撤销。
- 自 0.3.0 起，整帖请求由保持打开的侧栏直接等待结果，不依赖可能被 Tabbit 在长请求期间回收的 Manifest V3 后台工作线程；关闭侧栏、切帖或切换标签页仍会取消等待。
- API 密钥只存在 `chrome.storage.session`，浏览器会话结束后清除，不同步、不导出。
- 请求不包含帖子 URL、官方 PID/SPID、精确时间、原用户名、图片、Cookie、密码或贴吧登录信息。
- 同一帖子快照、端点、模型和模式在当前浏览器会话中只调用一次；失败或超时不自动重试，必须由吧务点击“重新分析”。
- 2.3.0 分析协议会安全规范化 Qwen/DeepSeek 常见的 JSON 差异，并仅依据父子回复、明确楼层引用、“楼上”、@或点名关系聚合互动链；无关楼层会在本地拆分，报告中的具体回复会保留可点击定位。回复 ID 与规范 ID 仍须精确命中本地白名单，输出被截断时整份拒绝。
- 当前版本兼容 DeepSeek 偶尔把 `uncertainties` 和长文报告列表项返回为对象的情况：只取白名单中的说明和回复引用，异常单项仅显示忽略数量，不再使整份报告失败。这个兼容层不触及违规回复 ID、规范 ID、证据或置信度。
- 思考模式的 `reasoning_content` 不会被显示、缓存或拼进结果；侧栏只使用模型的最终 `message.content`。
- 请求体超过安全字节或保守 token 上限时零请求，不截断、不只发送前半帖。
- 模型返回的理由文字不会直接成为公开文案；界面始终按模型给出的合法规则 ID 重新读取本地规范原文。

## 开发与验证

```bash
npm run typecheck
npm test
npm run build
npm run evaluate:example
```

`npm run evaluate:example` 只验证旧版本地启发式分析器的评估工具与语料格式；生产侧栏已不再使用这套本地判定。需要回归这部分遗留代码时，可将至少 30 个经人工标注、已脱敏的案例放入被 Git 忽略的 `evaluation/private/`，再运行：

```bash
npm run evaluate -- evaluation/private/corpus.json
```

该评估命令不调用云端模型，也不能代表整帖 AI 审阅质量；500 条 DOM 读取性能另由提取器测试覆盖。真实语料没有随代码提交，避免把吧友发言和用户名长期复制进仓库。

## 当前限制

- 只读端点只能返回当前账号/匿名会话可见的回复；已删除、审核中或权限不可见的内容无法绕过贴吧限制读取，数量差额会明确展示。
- 图片和视频内容不做 OCR；图片数量会计入覆盖缺口。
- 贴吧接口或 DOM 改版后可能需要更新适配；接口异常、加载中、结构不支持和解析异常会分别提示，空结果不会保存为有效审阅会话。
- `sync`、`page_pc` 等属于贴吧网页使用的非公开只读接口，可能随时调整或受平台规则约束；使用者应自行确认其账号与场景符合贴吧规则。
- 模型仍可能误解引用、反讽、熟人玩笑或事实真伪；所有结论和可点击证据都必须由吧务回到原帖人工复核。
- 首页全吧风险队列、OCR、团队共享后台和自动处罚均不在首版范围内。
